# Dependency jars

`build.gradle` compiles against the following local jars. They are not committed
to this repository; place them in this folder before running `gradle build`.

| File | Purpose |
| --- | --- |
| `create-1.21.1-6.0.10.jar` | Create 6.0.10 |
| `aeronautics-1.3.2.jar` | Create: Aeronautics API |
| `simulated-1.3.2.jar` | Create: Simulated API |
| `sable-neoforge-1.21.1-2.0.6.jar` | Sable physics |
| `sable-companion-common-1.21.1-1.6.0.jar` | Sable companion API |
| `flywheel-1.0.6.jar` | Flywheel rendering |
| `ponder-1.0.82.jar` | Ponder scenes |
| `registrate-1.3.0.jar` | Create registrate |

The exact filenames are referenced in `build.gradle`.
